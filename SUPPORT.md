# Support

## Product downloads and official Sync

Use [doodlenote.ai](https://www.doodlenote.ai) for signed downloads and
information about the official hosted Sync service.

## Public bugs and feature requests

Search the [GitHub issue tracker](https://github.com/Onyx-Dev-Labs/doodle-note/issues)
before opening a report. Use the provided templates and remove meeting content,
credentials, account details, email addresses, and other personal information.

Community support is provided on a best-effort basis. The public repository
does not create a response-time or compatibility commitment for forks,
self-hosted servers, beta platforms, or custom builds.

## Security and privacy reports

Do not open a public issue for a vulnerability or privacy exposure. Follow the
private process in [SECURITY.md](SECURITY.md).
