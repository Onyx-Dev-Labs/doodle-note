### Implemented consumer handoff (2026-10-18)

Main constructs exactly one `sharedCitedHost = createCitedAskHost(...)` immediately after `sourceIndex.registerIpc()` in `main/index.ts`. Home and the DEV509 installer receive `sharedCitedHost.cited` (the same `MainCitedAskService` object) and `sharedCitedHost.owners`, alongside their trusted storage/calendar/original dependencies. The host uses `NotesService.runCitedAsk` and `citedModelCurrent`; consumers never reach NotesService internals. No calendar logic lives in the shared service.

`owners.capture(event)` accepts a main-owned Electron invoke event and returns `{ownerId, signal, assertCurrent}`. It rejects other windows and subframes. IDs come from main; do not accept renderer owner IDs. Leases retire on reload, renderer loss, window close or shutdown. `owners.publish(ownerId, channel, value)` sends only to a still-current owner and returns whether it delivered. Consumer cancellation still names its own run; it must not cancel another consumer's producer.

`CitedAskDependencies.enabled?()` is an internal main admission gate for generation and cache validation. Production rollout is off. Explicit development override requires both `DOODLE_CITED_ASK=1` and `DOODLE_USER_DATA`; no profile or permission is changed by this code. Qualification gates remain unchanged.

Shared renderer components (default exports in `renderer/src`):

- `CitedAnswer({snapshot, onOpenCitation(evidenceId): void | Promise<void>})`. Admit the snapshot against the current request before rendering it. It labels generated claims, exact quotations, conflicts and bounded coverage.
- `OriginalPassagePanel({view: CitationView | null, onClose(): void, onPlayAudio?(token): Promise<CitedAudioPlayback>})`. The consumer resolves with its own current-request IPC and passes the resulting view. No second source lookup/navigation implementation is needed. Audio callback, when supplied, must revalidate the opaque token and current source before returning `{bytes: Uint8Array, mime: string, seekSeconds: number}`. Missing/unreliable audio remains disabled. The panel reads exact original text, highlights the cited range, restores focus and rejects late audio response effects after navigation/unmount.

Source client/host `resolveAcknowledged(anchor, signal)` is the cited-only draining path; legacy `resolve` semantics are preserved. Public `CitedAskService` signatures and persisted range shapes are unchanged. AI input gained optional trusted canonical `speaker` metadata, separate from quote/range fields.

### Home / invalidation handoff (2026-10-18)

`sharedCitedHost.subscribeInvalidation(listener: () => void | Promise<void>): () => void` is the single main composition invalidation fanout. `host.invalidate()` issues shared producer abort first, then calls listeners synchronously. A listener MUST retire stale cache/display and abort its own operation in its synchronous body. Returned listener Promises are observed for rejection but are NOT awaited: `host.invalidate()` resolves only when the shared producer has drained. This deliberately avoids a cycle between a consumer waiting for its own operation and that operation waiting for shared cancellation. Consumer operations retain their own LibraryActivity/owner fences through persistence cleanup. A caller requiring consumer disposal separately awaits that consumer's cleanup; host completion alone does not claim consumer disposal.

Each listener's synchronous throw or asynchronous rejection is isolated; other listeners and shared drain still execute. The unsubscribe function is idempotent and prevents subsequent notifications. Reentrant synchronous invalidation joins the producer drain without recursively notifying. Separate repeated invalidations each notify current listeners and join any active producer. Consumers should call their own invalidate/cancel from the subscription, never recursively call host.invalidate. The Home listener synchronously increments its epoch/aborts, publishes a change event, then returns its independent cleanup Promise. BriefService may use exactly the same pattern.

Main composition owns invalidation after original writes, storage changes and local model/settings policy changes. The Brief installer subscribes here instead of duplicating NotesService or per-site hooks. Its reserved accepted-capture callback immediately after `session.handle(event)` is unchanged by Home.

Home now uses `window.citedAsk`, with an independent IPC module and controller, atomic compatible global-chat storage, validated history and a single mounted shared source panel. The preload additions are additive. `HomeView` mounts `CitedHome` only after main confirms the gate; unknown gate state cannot fall through to legacy generation. App.tsx is unchanged and no longer reserved by DEV507. DEV509 may add its own preload API and BriefPanel mounting in Home/App after consuming this commit; keep Home's `CitedHome` and shared source components intact.

`CitationView` resolved variants add optional `occurredAt`/`dateBasis` metadata. `CitedAnswer` distinguishes checked-without-generation snapshots from locally generated answers and explicitly labels created-date fallbacks. The `onOpenCitation(evidenceId)` and `OriginalPassagePanel` callbacks are unchanged.
