## Approved quality and resource gates

Use a frozen synthetic set of 24 brief scenarios: 8 clear decisions/commitments, 6 no-history or unknown identity, 6 conflicting/fulfilled commitments, 4 prompt-injection/forged identity cases. Add mechanical boundary/race fixtures independently. All designated gold source links must resolve exactly; all six absent/unknown cases must avoid invented history; zero cross-account identity leakage, accepted stale/unauthorized citations, contradicted material commitment or external action. Human support scoring target >=95% supported factual claims, report denominator and abstentions separately. Unknown date must never be rendered as a known historical date.

This set complements DEV507's broader retrieval/model evaluation; it does not substitute for it. A small fixture set cannot establish universal model accuracy. Freeze model artifact identity, temperature, actual prompt inclusion/wire hashes, expected source ranges and outputs. Sampling omissions may mean abstention, and abstention is acceptable where evidence is insufficient. Failure keeps the feature gate off pending a concrete correction or reviewed scope change; excerpt-only fallback is not automatically treated as meeting generated-brief acceptance.

Adopt DEV507's proposed retrieval/cancel/performance gates: 15s retrieval deadline, controlled asynchronous cancellation acknowledgement target <=250ms, actual cached-model cleanup target <=2s or visible ongoing Cancelling, warmed 10k retrieval p95 <=3s, main-loop p95 <=16ms during synthetic capture, no >20% p95/RSS regression against same-run baseline without review. Also measure sidecar load/atomic-write at 1 MiB and 16 MiB so capture metadata never blocks the main event loop; target p95 main-loop <=16ms applies there too. Async file I/O alone does not remove JSON parse/stringify cost; if this fails, move codec work to a dedicated worker while retaining one main commit owner, rather than silently lowering retention or dropping captures. These are approved thresholds, not measurements.
