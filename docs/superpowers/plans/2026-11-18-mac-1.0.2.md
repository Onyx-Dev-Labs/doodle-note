# DoodleNote macOS v1.0.2 Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans to implement this plan task by task after implementation is requested. No delegation, commits, merge, packaging or publication is authorized by this planning request.

**Goal:** Ship a qualified Mac maintenance release that completes long local note generation, verifies safe quit after generation failures, and supports explicit OpenAI regional routing.

**Architecture:** Keep the existing local-first notes pipeline and actual producer cancellation. Measure and adjust bounded condensation workloads rather than removing safeguards. ## Review Focus

1. Slow first-token processing: allow supported healthy work under a measured policy without interpreting absent decoding tokens as proof of a stall (Task 2).
2. More/smaller chunks: final reduction must still fit; preserve middle facts and never save truncated output as complete notes (Task 2).
3. Timeout/cancel racing Quit or updater: retain actual native ownership and distinguish ordinary exit from installer handoff (Task 3).
4. Saved region changes while a catalog request is pending: never show an old destination's results or silently fall back to Global (Task 4).
5. Existing profiles and older installed versions: preserve defaults/data, and explain that downgrading can ignore a regional setting (Tasks 4–5).
