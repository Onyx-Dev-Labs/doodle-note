# DoodleNote open-source model

DoodleNote's source code is available under the [MIT License](../LICENSE).
You may use, modify, fork, self-host, and redistribute the software under the
terms of that license.

## Free local app

Local capture, transcription, notes, folders, search, and the opt-in local MCP
server are free. They run on the user's device and do not require a DoodleNote
account or impose meeting limits.

## Optional hosted Sync

Onyx Dev Labs operates the official DoodleNote Sync service at
[doodlenote.ai](https://www.doodlenote.ai). It provides hosted backup,
multi-device sync, the web library, share links, workspaces, and hosted agent
access for $10 per user per month.

The Sync server source is included in this repository under MIT. Customers pay
for the official hosting, storage, operations, and support, not for access to a
private codebase. You may also run your own server by following
[SELF-HOSTING.md](../SELF-HOSTING.md).

Canceling official Sync does not delete local notes. It stops hosted syncing
until the subscription is restored.
