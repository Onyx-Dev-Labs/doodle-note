# ONY-276 — Transcript-toggle arrow alignment

Source baseline: `68fbc7c0507c536ce04caed03dabf19f4935ede4` (`main`).
QA date: 2026-09-09. Tested the actual React MeetingView and its stylesheet in
local Chrome on macOS, with synthetic engine events and fictional note content.
No microphone, account, customer data, OS permission changes or installed app were used.

## Reproduction and fix

The baseline screenshots reproduce different vertical placement for the two font
characters: the downward arrow sits below the center of its hover circle. The
28×28 button was already flex-centered. Changing flex alignment would not remove
the glyph's asymmetric font metrics.

Both recorder branches now use the existing SVG Icon primitive with mirrored
chevrons, identical view boxes and symmetric visible bounds. The native button,
handler, dimensions, spacing, colors and focus treatment remain in place. Each
button explicitly names its Show/Hide action and exposes `aria-expanded`; the SVG
is decorative. There is no CSS, permission, capture lifecycle or template-arrow change.
