# Synthetic Home lifecycle regression

Start from repository root with `pnpm --filter desktop exec tsx scripts/dev507-home-qa/server.mts`. Open the printed loopback URL in a new isolated/incognito browser. In that page evaluate `(await import('/regressions.js')).run()` through the browser automation tool. Nine assertions exercise focus during generation, late history, generation error, cancellation, real source invalidation, owner revocation, older-history/newer-refresh ordering, late citation replies and unmount. The final assertion unmounts the component; reload before another run. Stop with Ctrl-C to remove the synthetic temporary originals/history.

The harness imports the actual React Home/source components, Home controller, shared service, atomic store, original retrieval/validation and prompt builder. It supplies a deterministic synthetic generator, local temporary files and a test-only HTTP transport. It never launches Electron or touches existing application profiles, accounts, models, permissions or devices. HTTP is not production IPC; main IPC owner/frame checks have their own repository tests. Fixture setup is shared in shape with home-cited-controller.test.ts; the assertions exercise rendered behavior and persisted results rather than implementation details.

The server binds an ephemeral IPv4 loopback port. It serves only this test application and its repository imports through Vite. No browser profile is selected by the server. Do not substitute the installed application's URL or personal library.

Evidence in `docs/qa/dev507/home-*.json` records the author run. `home-focus-old.json` uses the exact 02c0bb4 CitedHome source (identical to f59cd59 for the affected component) imported separately into the same real-controller harness, not an edited approximation. It saves a valid answer while hiding it. `home-lifecycle-nine.json` records the fixed component's nine passing scenarios. This is synthetic renderer verification, not native/model/audio/semantic qualification.
