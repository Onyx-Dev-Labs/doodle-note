# Synthetic brief renderer QA

From repository root run `pnpm --filter desktop exec tsx scripts/dev509-brief-qa/server.mts`. Open its printed loopback URL in a fresh incognito browser. Evaluate `(async () => (await import('/regressions.js')).run())()` in that page. Ten scenarios exercise actual Home Open brief, BriefPanel, controller, main IPC handlers/owners, installer, context store/codec, real source worker, shared cited service and original passage UI. HTTP/SSE is a test transport, not Electron IPC. A deterministic synthetic generator replaces the local model; timingless originals disable Play. No profile, credential, provider, model, device or recording access occurs.

The server creates a temporary synthetic library, binds only IPv4 loopback on an ephemeral port, and binds Vite's hot reload to that same server. Ctrl-C stops workers and removes the temporary library. Restart the server before rerunning the complete scenario sequence: its explicit corrections/forget/failure tests deliberately change fixture state. Do not point this harness at an existing application/library or expose its port remotely.

The assertions cover metadata-only Open, no-history without model invocation, explicit identity correction, event-only history link, exact source/date rendering and focus return, refresh without inference, [] without fallback, cancellation acknowledgement and retry, account disconnect withholding, model failure and explicit forget. Original-byte preservation is checked. Browser evidence at `docs/qa/dev509/brief-renderer.json` and four screenshots records author verification of production commit910e8a4; the harness was then uncommitted. It does not qualify actual model quality, Google/Microsoft providers, Electron transport/packaged startup, audio decoding/audibility, native capture or Windows.
